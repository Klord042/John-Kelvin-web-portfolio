# SparklePro Cleaning Services

A polished responsive landing page for a fictional professional cleaning company.

## Built with
- HTML5
- CSS3
- Responsive design
- Basic JavaScript form interaction

## Features
- Responsive navigation
- Hero section with service CTA
- Service cards
- About/benefits section
- 3-step booking process
- Quote request form
- Mobile-friendly layout

## Portfolio note
This project demonstrates semantic HTML, responsive CSS, layout design, forms, and conversion-focused UI.
